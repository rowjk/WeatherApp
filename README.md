#  Python Android Weather App (V0.052)
這是一個使用 Python (Kivy/KivyMD) 開發的 Android 天氣應用程式。
它可以即時查詢全球城市的天氣狀況，並支援繁體中文顯示。

## ✨ 功能特色 (Features)
- **即時天氣**：串接 WeatherAPI 取得最新氣象資訊。
- **多日預報**：顯示未來幾天的天氣預測。
- **城市管理**：可搜尋並釘選 (Pin) 常用的城市。
- **繁體中文介面**：針對台灣使用者優化的 UI 與字體。
- **質感動畫**：晴天旋轉、雨天跳動的動態圖示。

**系統需求：**
- Android 5.0 (Lollipop) 以上版本
- 需開啟網路連線

## 🛠️ 開發技術 (Tech Stack)
- **語言**：Python 3.10 (Powered By Gemini 3.0 PRO)
- **框架**：Kivy 2.3.0, KivyMD 1.1.1
- **API**：WeatherAPI.com
- **打包工具**：Buildozer (via Google Colab)
